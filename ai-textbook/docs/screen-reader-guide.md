# Screen Reader Guide

## Using the Course with Screen Readers

This guide provides information on how to navigate and use the Physical AI & Humanoid Robotics Course materials with screen readers and other assistive technologies.

## Supported Screen Readers

Our course materials are tested and compatible with the following screen readers:

- **JAWS (Job Access With Speech)** - For Windows users
- **NVDA (NonVisual Desktop Access)** - Free screen reader for Windows
- **VoiceOver** - Built into macOS and iOS devices
- **Narrator** - Built into Windows 10 and later
- **TalkBack** - Built into Android devices

## Navigation Structure

### Page Structure
Each page follows a consistent structure that makes navigation easier:
1. **Skip to Content** link (appears when tabbing)
2. **Header** with site navigation
3. **Main Content** area
4. **Footer** with additional links

### Heading Structure
- H1: Main page title
- H2: Major sections
- H3: Subsections
- H4: Detailed subsections

Use your screen reader's heading navigation to jump between sections quickly.

## Keyboard Shortcuts

### Standard Navigation
- **Tab**: Move to next interactive element
- **Shift + Tab**: Move to previous interactive element
- **Arrow keys**: Navigate within content and lists
- **Enter/Space**: Activate links and buttons

### Screen Reader Specific Shortcuts
Most screen readers support these shortcuts:
- **H**: Jump to next heading
- **B**: Jump to next button
- **L**: Jump to next link
- **T**: Jump to next table
- **F**: Jump to next form field

## Course-Specific Navigation

### Table of Contents
- Each page includes a table of contents for quick navigation
- Use heading navigation to jump to specific sections
- Breadcrumb navigation shows your current location

### Code Examples
- Code blocks are properly labeled and structured
- Use your screen reader's text navigation to read code line by line
- Code examples include descriptive captions

### Navigation Menus
- Main navigation is keyboard accessible
- Dropdown menus can be opened with keyboard
- Submenus are properly announced

## Content Types and How to Navigate Them

### Text Content
- Standard reading with screen reader
- Headings provide structure and context
- Links are clearly announced with their purpose

### Code Examples
- Code blocks are announced as "code block" followed by content
- Syntax highlighting information is available if supported
- Line numbers help with reference

### Lists and Tables
- List items are properly structured and announced
- Tables include headers and are navigable by row/column
- Complex tables include summaries

### Images and Graphics
- All meaningful images include alt text descriptions
- Complex diagrams include detailed descriptions
- Decorative images have empty alt attributes

## Tips for Using Course Materials

### Reading Documentation
1. Use heading navigation to quickly find specific topics
2. Use search functions to find specific terms
3. Navigate by links to jump to related content
4. Use the table of contents for overall structure

### Working with Code Examples
1. Listen to the descriptive text before code blocks
2. Use text navigation to read code line by line
3. Note any comments within code for additional context
4. Refer to the surrounding text for usage context

### Completing Exercises
1. Use form navigation to work through exercise inputs
2. Listen carefully to instructions and requirements
3. Use heading navigation to find different parts of exercises
4. Take advantage of skip links to bypass repetitive navigation

## Accessibility Settings

### High Contrast Mode
- The site supports high contrast mode for better visibility
- Colors adjust automatically based on system settings
- Text remains readable in high contrast mode

### Reduced Motion
- Animations and transitions are minimized or disabled
- Content remains stable during navigation
- Focus indicators are always visible

### Text Scaling
- Content scales properly up to 200% zoom
- Layout remains functional at larger text sizes
- No horizontal scrolling needed for normal content

## Troubleshooting Common Issues

### Page Not Reading Properly
- Try refreshing the page
- Check if your screen reader is up to date
- Ensure JavaScript is enabled
- Try a different browser if issues persist

### Missing Descriptions
- If you encounter an image without description, report it
- Use context clues from surrounding text
- Contact support for alternative descriptions

### Navigation Issues
- Ensure you're using the latest version of your screen reader
- Check for updates to the course platform
- Try clearing your browser cache
- Contact support if issues continue
