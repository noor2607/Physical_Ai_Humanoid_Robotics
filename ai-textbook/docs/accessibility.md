# Accessibility Statement

## Our Commitment to Accessibility

The Physical AI & Humanoid Robotics Course is committed to providing an accessible learning experience for all students, including those with disabilities. We strive to ensure that our educational materials and digital platforms are usable by everyone, regardless of their abilities or the assistive technologies they use.

## Web Accessibility Standards

Our course materials follow the Web Content Accessibility Guidelines (WCAG) 2.1 at the AA level, which means our content is:
- **Perceivable**: Information and user interface components must be presentable to users in ways they can perceive
- **Operable**: User interface components and navigation must be operable
- **Understandable**: Information and the operation of user interface must be understandable
- **Robust**: Content must be robust enough that it can be interpreted reliably by a wide variety of user agents, including assistive technologies

## Accessibility Features

### Keyboard Navigation
- All interactive elements are accessible via keyboard
- Clear focus indicators show which element is currently focused
- Logical tab order follows the visual flow of content
- Skip-to-content links are available at the top of each page

### Screen Reader Support
- Proper heading structure (H1, H2, H3, etc.) for content organization
- Alternative text for all meaningful images
- Semantic HTML elements for proper content structure
- ARIA labels for interactive elements when needed

### Visual Accessibility
- High contrast between text and background
- Support for high contrast mode
- Sufficient color contrast ratios (4.5:1 for normal text, 3:1 for large text)
- Text that can be resized up to 200% without loss of functionality
- No information conveyed by color alone

### Motion Sensitivity
- Animations and transitions can be reduced based on user preference
- Warning provided before content that may cause seizures
- No flashing content that could trigger photosensitive reactions

## Supported Assistive Technologies

Our course materials are designed to work with the following assistive technologies:
- Screen readers (JAWS, NVDA, VoiceOver, Narrator)
- Screen magnification software
- Voice recognition software
- Alternative input devices
- Braille displays

## Content Accessibility

### Documentation
- All text content is available in plain text format
- Code examples include detailed explanations
- Images include descriptive alt text
- Complex diagrams include detailed descriptions
- Videos include captions and audio descriptions where applicable

### Code Examples
- Syntax highlighting for better readability
- Proper code structure and indentation
- Descriptive variable and function names
- Inline comments explaining complex logic
- Alternative formats available upon request

## Feedback Process

We welcome feedback about accessibility issues and suggestions for improvement. If you experience any problems or have suggestions, please:

1. Contact our accessibility coordinator directly
2. Use the feedback form on our website
3. Report issues through the course platform
4. Email accessibility@physical-ai-course.com

## Technical Requirements

To access our course materials, you will need:
- A modern web browser (Chrome, Firefox, Safari, Edge)
- JavaScript enabled
- Cookies enabled
- Screen resolution of at least 1024x768 (higher recommended)
- Minimum internet connection speed for content loading

## Continuous Improvement

We continuously work to improve the accessibility of our course materials. Our development team regularly reviews and updates content to meet current accessibility standards. We also welcome user feedback to identify and address accessibility issues.

## Third-Party Content

While we strive to ensure all content on our site is accessible, some third-party content may not meet our accessibility standards. If you encounter inaccessible third-party content, please report it to us so we can work with the provider or provide an alternative.

## Compliance Status

This website is partially conformant with WCAG 2.1 level AA. Partially conformant means that some parts of the content do not fully conform to the accessibility standard.
