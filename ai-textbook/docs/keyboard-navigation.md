# Keyboard Navigation Guide

## Navigating the Course with Keyboard Only

This guide provides comprehensive information on how to navigate the Physical AI & Humanoid Robotics Course using only a keyboard, without requiring a mouse or other pointing device.

## Basic Keyboard Navigation

### Standard Navigation Keys
- **Tab**: Move forward to the next interactive element (links, buttons, form fields)
- **Shift + Tab**: Move backward to the previous interactive element
- **Enter**: Activate links, buttons, and submit forms
- **Space**: Activate checkboxes, radio buttons, and buttons
- **Arrow Keys**: Navigate within dropdowns, radio button groups, and other controls
- **Escape**: Close dropdown menus, modals, and other pop-up elements

## Page Structure Navigation

### Skip Navigation Links
Each page includes a "Skip to Content" link that appears when you start tabbing. This allows you to bypass repetitive navigation elements and go directly to the main content.

### Headings Navigation
While not a keyboard key itself, many browsers and assistive technologies support navigation by headings:
- Use **Alt + F10** (Chrome/Vivaldi) or **Insert + F6** (JAWS) to navigate by headings
- Headings follow a logical hierarchy (H1, H2, H3, etc.)
- Use headings to quickly jump between sections

## Main Navigation

### Top Navigation Bar
- **Tab** to move between navigation items
- **Enter** or **Space** to activate menu items
- **Arrow keys** to navigate within dropdown menus
- **Escape** to close dropdown menus

### Sidebar Navigation
- **Tab** to move between sidebar items
- **Enter** to navigate to selected page
- **Arrow keys** to expand/collapse sections (where applicable)
- **Home/End** to jump to top/bottom of sidebar

## Content Areas

### Documentation Pages
- **Tab** moves between links, buttons, and form elements within content
- **Shift + Tab** moves backwards through content elements
- Use **Tab** to find specific links or interactive elements
- Code blocks are focusable and can be scrolled with arrow keys if needed

### Code Examples
- Code blocks receive focus as single elements
- **Tab** moves to next element after code block
- Use browser zoom or page scaling to make code more readable
- Copy buttons (if present) are keyboard accessible

### Tables and Lists
- **Tab** moves between table/list elements
- **Arrow keys** may be needed to navigate within complex tables
- Headers are properly marked for navigation context

## Interactive Elements

### Buttons
- All buttons are keyboard accessible
- Visual focus indicator shows current element
- **Space** or **Enter** activates buttons
- Button purpose is clearly indicated in text

### Forms
- **Tab** moves between form fields in logical order
- **Enter** may submit forms (where appropriate)
- Error messages are properly associated with form fields
- Required fields are clearly indicated

### Dropdown Menus
- **Tab** to focus on dropdown
- **Enter** or **Space** to open/close dropdown
- **Arrow keys** to navigate options
- **Enter** to select option
- **Escape** to close without selecting

## Special Course Features

### Code Editors (if embedded)
- **Tab** may be used for indentation (may need to hold Shift)
- **Arrow keys** for cursor movement
- **Ctrl/Cmd + S** to save (if applicable)
- **Ctrl/Cmd + Z** for undo (if applicable)

### Interactive Demos
- All interactive elements within demos are keyboard accessible
- Clear focus indicators show current selection
- Instructions provided for keyboard interaction
- Alternative interaction methods available if needed

## Navigation Tips

### Efficient Navigation
1. **Use Skip Link**: Always use the skip navigation link when first arriving on a page
2. **Tab Order**: Follow the logical tab order to understand page structure
3. **Focus Management**: Pay attention to where focus moves after actions
4. **Landmarks**: Use HTML5 landmarks (header, nav, main, footer) to orient yourself

### Common Patterns
- **Navigation**: Top menu, then sidebar, then main content
- **Content**: Headings, paragraphs, links, code blocks, then footer
- **Forms**: Logical progression from top to bottom
- **Buttons**: Primary actions are often first in tab order

## Accessibility Features

### Focus Indicators
- Strong, visible focus indicators on all interactive elements
- Focus indicators meet WCAG 2.1 AA contrast requirements
- Focus remains visible when using keyboard navigation
- Custom focus styles for different element types

### ARIA Labels
- Proper ARIA labels for complex interactive elements
- Descriptive labels for form fields
- Status messages announced to screen readers
- Landmark regions properly defined

## Troubleshooting Keyboard Navigation

### If Tab Navigation Stops Working
- Check if focus has moved to an embedded element (like an iframe)
- Try **Shift + Tab** to move backwards
- Refresh the page if necessary
- Ensure no JavaScript errors are occurring

### If Focus Gets Lost
- Use browser's address bar to return to page
- Reload the page
- Start navigation from the beginning
- Contact support if issues persist

### Navigation Takes Too Long
- Use skip navigation links when available
- Consider using browser extensions for faster navigation
- Use headings navigation if supported by your browser
- Look for direct links to frequently accessed content

## Browser-Specific Instructions

### Chrome
- **F6** to move focus between main areas
- **Ctrl + U** to view page source for structure
- Extensions available for enhanced keyboard navigation

### Firefox
- **F6** to move between content areas
- **Ctrl + Tab** to move between tabs
- Built-in accessibility features in Preferences

### Safari
- Enable accessibility features in Preferences
- **Option + Command + U** for accessibility inspector
- VoiceOver integration for enhanced navigation

### Edge
- Similar to Chrome for navigation
- Built-in accessibility tools
- Integration with Windows Narrator

## Best Practices for Keyboard Users

### Navigation Efficiency
1. **Learn the layout**: Familiarize yourself with the standard page structure
2. **Use skip links**: Always use skip navigation links first
3. **Understand focus**: Pay attention to focus indicators to know your location
4. **Plan your route**: Think about the most efficient navigation path

### Content Interaction
1. **Read labels**: Pay attention to button and link labels before activating
2. **Check context**: Ensure you understand what element you're interacting with
3. **Use confirmation**: For important actions, verify before confirming
4. **Save progress**: Regularly save work in forms or exercises
