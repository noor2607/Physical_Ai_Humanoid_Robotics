# Course Overview: Physical AI & Humanoid Robotics

Welcome to the comprehensive **Physical AI & Humanoid Robotics** course! This program takes you through the complete journey from fundamental robotics concepts to advanced conversational AI integration.

## Course Structure

This 13-week course is organized into four progressive modules, each building upon the previous one:

### [Module 1: Robotic Nervous System (ROS 2)](./module-1-ros2/index.md)
- Foundation in robot communication and coordination
- Core ROS 2 concepts: nodes, topics, services, actions
- Python integration and client libraries
- URDF and robot modeling
- [Module 1 Exercises](./exercises/index.md#module-1-exercises-ros-2-fundamentals)

### [Module 2: Digital Twin (Gazebo & Unity)](./module-2-simulation/index.md)
- Physics simulation principles and parameters
- Sensor simulation and integration
- Environment setup and world creation
- Unity visualization for advanced interfaces
- Builds on concepts from [Module 1](./module-1-ros2/index.md)

### [Module 3: AI-Robot Brain (NVIDIA Isaac)](./module-3-isaac/index.md)
- Isaac Sim for robotics simulation
- Isaac ROS integration
- VSLAM (Visual Simultaneous Localization and Mapping)
- Path planning and navigation algorithms
- Integrates concepts from [Module 1](./module-1-ros2/index.md) and [Module 2](./module-2-simulation/index.md)

### [Module 4: Vision-Language-Action (VLA)](./module-4-vla/index.md)
- Voice-to-action systems and speech recognition
- LLM integration for cognitive planning
- Conversational robotics and humanoid control
- Capstone project integrating all previous modules
- Utilizes knowledge from [Module 1](./module-1-ros2/index.md), [Module 2](./module-2-simulation/index.md), and [Module 3](./module-3-isaac/index.md)

## Learning Path

Each module is designed to progressively build your skills:

- **Beginner**: Start with [Module 1](./module-1-ros2/index.md) to establish your foundation in robotic systems
- **Intermediate**: Continue with [Modules 2-3](./module-2-simulation/index.md) to develop simulation and AI integration skills
- **Advanced**: Complete [Module 4](./module-4-vla/index.md) to master conversational robotics and complete the capstone project

## Prerequisites

- Basic programming experience (Python preferred)
- Understanding of linear algebra and calculus
- Familiarity with Linux command line
- Interest in robotics and AI

## Technology Stack

This course leverages cutting-edge technologies in robotics and AI:

- **ROS 2 (Humble Hawksbill)**: Robot communication and coordination framework
- **Gazebo**: Physics simulation for robot testing
- **Unity**: Advanced visualization and interaction
- **NVIDIA Isaac**: AI acceleration and robotics platform
- **Large Language Models**: Natural language understanding and reasoning
- **Docusaurus**: Course documentation and learning management

## Hardware Requirements

- **Minimum**: Intel i7/AMD Ryzen 7, 16GB RAM, modern GPU
- **Recommended**: NVIDIA RTX 3070+, 32GB RAM, Ubuntu 20.04/22.04 LTS
- **For Physical Testing**: Unitree Go1 or similar humanoid robot (optional)
