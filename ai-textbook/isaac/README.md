# Physical AI & Humanoid Robotics - Isaac Configuration

This directory contains NVIDIA Isaac configuration files and templates for the course.

## Directory Structure

- `configs/` - Isaac configuration files for different robotics components
- `scripts/` - Isaac launch and utility scripts
- `extensions/` - Isaac extensions and custom modules

## Configuration Files

- `robot_config.json` - Main robot configuration with navigation and perception settings
- `perception_pipeline.json` - Perception pipeline configuration for feature detection and pose estimation

## Setup

1. Install NVIDIA Isaac Sim and Isaac ROS
2. Ensure your system meets the hardware requirements (RTX 3070 or higher)
3. Configure the paths in the JSON files to match your environment

## Usage

These configuration files are used in the course to demonstrate:
- Robot navigation and path planning
- Computer vision and perception
- SLAM (Simultaneous Localization and Mapping)
- Manipulation and control systems
