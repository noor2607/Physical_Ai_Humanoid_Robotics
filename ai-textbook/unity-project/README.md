# Physical AI & Humanoid Robotics - Unity Visualization Project

This Unity project contains visualization components for the Physical AI & Humanoid Robotics course.

## Project Structure

- `Assets/Scenes/` - Unity scenes for visualization
- `Assets/Scripts/` - Unity C# scripts for visualization and interaction
- `Assets/Prefabs/` - Reusable game objects
- `Assets/Models/` - 3D models for robots and environments
- `Assets/Materials/` - Materials and textures

## Setup

1. Install Unity Hub
2. Install Unity 2022.3 LTS (or later recommended version)
3. Open this project in Unity
4. The project is configured for the Physical AI & Humanoid Robotics course

## Purpose

This Unity project serves as a visualization environment for the course, allowing students to:
- Visualize robot behaviors and movements
- Create interactive 3D environments
- Integrate with ROS using ROS-TCP-Connector
- Simulate humanoid robot interactions
