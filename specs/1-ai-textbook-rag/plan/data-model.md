# Data Model: AI Textbook RAG Chatbot

**Feature**: 1-ai-textbook-rag
**Created**: 2025-12-25
**Status**: Complete

## Entities

### Document
Represents a single documentation page from the sitemap

**Fields**:
- `id` (string): Unique identifier for the document (UUID)
- `url` (string): Source URL of the documentation page
- `title` (string): Title of the documentation page (extracted from HTML)
- `content` (string): Extracted and cleaned text content
- `chunk_id` (string): Identifier for this chunk of the document (for large documents)
- `chunk_text` (string): The specific chunk of text stored
- `chunk_index` (integer): Sequential index of this chunk within the document
- `embedding` (list[float]): Vector embedding of the chunk text (768 dimensions)
- `created_at` (datetime): Timestamp when the document was indexed
- `updated_at` (datetime): Timestamp when the document was last updated
- `source_hash` (string): Hash of the original content to detect changes

**Validation Rules**:
- URL must be a valid HTTP/HTTPS URL
- Content must not exceed maximum embedding model input length
- Embedding vector must have exactly 768 dimensions
- Title and content must not be empty

### Query
Represents a user query submitted to the system

**Fields**:
- `id` (string): Unique identifier for the query (UUID)
- `user_input` (string): Original user query text
- `query_embedding` (list[float]): Vector embedding of the query (768 dimensions)
- `session_id` (string): Session identifier for conversation context
- `timestamp` (datetime): When the query was made
- `response_generated` (string): The response generated by the system
- `retrieved_context_ids` (list[string]): IDs of document chunks used in response

**Validation Rules**:
- User input must not be empty
- Query embedding must have exactly 768 dimensions
- Session ID should follow standard session ID format

### RetrievedContext
Represents relevant document chunks retrieved for a query

**Fields**:
- `query_id` (string): Reference to the original query
- `document_id` (string): Reference to the relevant document chunk
- `content_snippet` (string): Relevant text snippet from the document
- `similarity_score` (float): Semantic similarity score (0.0 to 1.0)
- `rank` (integer): Rank of relevance in the result set
- `source_url` (string): Original URL of the documentation page
- `source_title` (string): Title of the source documentation page

**Validation Rules**:
- Similarity score must be between 0.0 and 1.0
- Rank must be a positive integer
- Query ID and document ID must reference existing records

### Session
Represents a user session with conversation history

**Fields**:
- `id` (string): Unique session identifier (UUID)
- `created_at` (datetime): When the session was started
- `last_activity` (datetime): When the session was last used
- `query_history` (list[Query]): List of queries in this session
- `metadata` (object): Additional session metadata (user info, etc.)

**Validation Rules**:
- Session ID must be unique
- Query history items must reference valid queries
- Session must have an expiration time

### IngestionLog
Tracks the ingestion process for monitoring and debugging

**Fields**:
- `id` (string): Unique identifier for the log entry (UUID)
- `sitemap_url` (string): URL of the sitemap being processed
- `status` (string): Status of the ingestion (pending, processing, completed, failed)
- `pages_processed` (integer): Number of pages successfully processed
- `pages_failed` (integer): Number of pages that failed to process
- `start_time` (datetime): When the ingestion started
- `end_time` (datetime): When the ingestion completed
- `error_details` (string): Details of any errors that occurred

**Validation Rules**:
- Status must be one of the allowed values
- Pages processed and failed must be non-negative integers
- Start time must be before end time (for completed tasks)

## Relationships

- **Session** 1-to-many **Query**: One session can contain multiple queries
- **Query** 1-to-many **RetrievedContext**: One query can retrieve multiple document chunks
- **Document** 1-to-many **RetrievedContext**: One document can be referenced by multiple queries

## State Transitions

### IngestionLog States
- `pending` → `processing`: When ingestion begins
- `processing` → `completed`: When all pages are processed successfully
- `processing` → `failed`: When ingestion encounters errors
- `completed` → `processing`: When re-ingestion is triggered

## Indexes

- Document: Index on URL for fast lookup
- Document: Index on created_at for time-based queries
- Query: Index on session_id for session-based retrieval
- RetrievedContext: Index on query_id for fast query result retrieval
- Session: Index on last_activity for session cleanup
